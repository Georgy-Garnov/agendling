# Security policy

Agendling stores CalDAV credentials locally (encrypted with Windows DPAPI, or AES-GCM with a key
kept in the desktop keyring on Linux) and talks only to the servers you configure.

If you find a security problem, please **don't open a public issue**. Report it privately via
[GitHub security advisories](https://github.com/Georgy-Garnov/agendling/security/advisories/new).
You'll get a reply as soon as possible, and a fix will be released before details are published.

Only the latest release receives security fixes.
